# Finnish School Python

## What Is Python?

Python is a **programming language** used to give instructions to computers and robots. It is easy to read and is good for beginners.

## Why Do We Use Python for mBot2?

We use Python to control mBot2 and tell it what to do. For example, we can display messages on the CyberPi screen and change the LED colours.

## What Is a Python Comment?

A comment is a note in the code that explains what the program does. Comments start with the # symbol, and Python does not run them.

Example:

```python
# This is a comment
print("Hello")
```

## Why Do We Display Text on a Screen?

Displaying text helps us show information, messages and results. On mBot2, we can display text using the CyberPi screen.

## Three Simple Python Examples

1. Display a message:

```python
print("Hello World")
```

2. Use a variable:

```python
name = "Lina"
print(name)
```

3. Do a calculation:

```python
print(5 + 3)
```
